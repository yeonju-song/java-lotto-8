#로또 프로그램

## 프로젝트 개요

사용자가 입력한 구입 금액에 따라 로또 티켓을 생성하고 
당첨 번호와 보너스 번호를 비교하여 로또 등수별 통계와 수익률을 계산하는 프로그램

이번 프로젝트를 구현할때 유지보수성, 가독성, 단위 테스트 용이성을 최우선으로 고려

## 요구사항

1. 구입 금액은 1,000원 단위로 입력
2. 로또 번호는 1~45, 중복 불가, 총 6개
3. 보너스 번호 입력
4. 당첨 등수는 아래 기준
- 1등: 6개 일치 → 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 → 30,000,000원
- 3등: 5개 번호 일치 → 1,500,000원
- 4등: 4개 번호 일치 → 50,000원
- 5등: 3개 번호 일치 → 5,000원
5. 당첨 통계와 수익률 출력 (소수점 둘째 자리 반올림)
6. 예외 처리 구현 (잘못된 입력 시 재입력)
7. 유지보수를 위해 기능별 함수 분리, Enum 사용, 메서드 길이 15라인 이하, 들여쓰기 depth 2 이하, else 사용 금지

## 설계 및 구현

1. 클래스 구조

<Application.java>
- 사용자 입력 처리 담당 : 구입금액, 당첨번호, 보너스번호
- 로또 티켓을 생성(makeLottoNumbers)
- 당첨 통계 계산(calculateResults) , 출력(printResults)
- 수익률 계산&출력(calculateProfit)

<Lotto.java>
- 로또 한 장을 나타냄
- 오름차순으로 정렬
- 번호검증 : 로또 번호 갯수, 로또 번호 중복, 로또 번호 범위

<Rank.java(Enum)>
- 등수별 정보 관리 : 당첨 등수, 당첨금, 출력 순서

2. 예외 처리 및 입력 검증

- 구입 금액 입력 시 1,000원 단위 검증
- 당첨 번호 입력 시 로또 번호 갯수(6개), 당첨 번호들 끼리의 중복, 로또 번호 범위 검증
- 보너스 번호 입력 시 당첨 번호 중복 여부 검증
- 잘못된 입력 발생 시 예외 메세지 출력 후 재입력 반복

3. 기능별 함수

- inputMoney : 구매 금액 입력
- makeLottoNumbers : 랜덤 번호 생성 후 Lotto 객채로 저장
- printLottoTickets : 구매한 로또 장수와 번호 출력
- inputWinningNumbers : 당첨 번호 입력 
- validateWinningNumbers : 당첨 번호 검증
- inputBonusNumber : 보너스 번호 입력
- calculateResults : 등수별 통계 계산
- printResults : 당첨 통계 출력
- calculateProfit : 총 수익률 계산 및 출력

4. 단위 테스트

JUnit5 + AssertJ를 사용하여 테스트 코드 작성:

<ApplicationTest.java>
- 로또 번호 정렬, 당첨 결과 계산, 수익률 계산 검증

<LottoTest.java>
- 로또 번호 갯수, 로또 번호 중복, 로또 번호 범위, 오름차순 정렬 검증

=> 단위 테스트를 통해 로직의 정확성과 예외 처리가 보장
